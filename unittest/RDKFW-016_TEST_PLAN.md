# RDKFW-016: privileged cache read

load_xconf_from_cache opens the fixed cache using O_NOFOLLOW/O_NONBLOCK/O_CLOEXEC and validates fstat on that same descriptor: regular file, daemon effective UID owner, no group/other write, nonempty size up to 1 MiB. It reads only the validated bounded size and removes raw cache-content logging. Rejected cache returns false to the existing fetch path. This does not authenticate malicious content written by a trusted/root process or change cache-writer provenance; kernel protection and producer security still matter.
