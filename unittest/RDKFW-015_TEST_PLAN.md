# RDKFW-015: cached artifact substitution

Before cached DownloadFirmware success or UpdateFirmware admission, validate the configured storage by walking directory components via no-follow openat descriptors. Every ancestor must be an effective-UID-owned directory without group/other write permissions. Artifact is opened relative to final directory no-follow/nonblocking and must be owned, regular, single-linked, nonempty and non-group/other-writable. Unsafe cache paths are rejected BEFORE fresh transfer; safe missing artifact may be downloaded. Cache checks now use configured DIFW_PATH consistently rather than hardcoded /opt/CDL.

This mitigates LOWER-PRIVILEGED local substitution by enforcing protected directory and file permissions; it does not pin the opened artifact through the external platform flasher. Another root/trusted peer can still replace paths after descriptor validation. Confirm threat model and storage-owner/consumer compatibility in security review; if root-peer replacement must be prevented, a descriptor/staged-artifact contract with the external flasher is still required before complete closure.
