Unregister's name used in post-removal logging is copied with g_autofree before removal so it does not become a dangling pointer. Existing sender-ownership check remains.

Memory validation: run a debug/symbolized daemon under the VM's available Valgrind/Memcheck or equivalent allocation profiler and drive equivalent repeated D-Bus operations without the existing tests replacing/killing that instrumented process.
